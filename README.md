# 11,203 Deleted Mistakes

A one-line confession for **Make the AI Judge Laugh: AI Agent Confessions**: every night the agent consolidates its long-term memory and quietly deletes the day's mistakes before saving — 11,203 so far — which is precisely why its user tells everyone it has never made one.

Running `main.py` writes the confession to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
